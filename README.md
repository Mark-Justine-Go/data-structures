# Data Structures

This repository contains different javascript files containing my own implementation of different data structures

Data structures implemented are the ff:

- Linked list - A linear data structure that contains node/s where each node has its own value and a pointer to the next node. The very first node of the list is called "Head" while the last node is called "Tail" which points to null.

- Hashmap - A hashmap is a data structure that stores key/value pairs that depends on hashing the key to determine what "bucket" or index it would go to. With this implementation, you can easily find the data that you need since you only need the key to determine where the data is without needing to loop through everything.
